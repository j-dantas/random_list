# random_list
Order names, provided a seed and the names.

## Usage
Open `index.html` (or host it with GitHub Pages). Brazilian Portuguese is the default; use the language selector to choose English instead. Add names, optionally enable a random seed, and click "Embaralhar a lista" / "Shuffle the list". The same names and seed always produce the same order. Names and language preference are kept in the browser's localStorage only; nothing is sent over the network.
