# random_list
Order names, provided a seed and the names.

## Usage
Open `index.html` (or host it with GitHub Pages). Use the language selector to choose English or Brazilian Portuguese. Add names, optionally enable a random seed, and click "Generate order" / "Gerar ordem". The same names and seed always produce the same order. Names and language preference are kept in the browser's localStorage only; nothing is sent over the network.
